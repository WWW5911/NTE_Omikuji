## 新增

- **對應維護 → 強制覆蓋…**：把 `rewards.csv`、`achievements.csv`、`events.csv`、`schedule.csv` 整份換成 **GitHub 最新資料** 或 **內建資料**。
  - 適合對應改亂了、刪掉太多，或想直接回到官方版本的時候。一般的「從 GitHub 更新」會保留你刪掉的列和改過的欄位，這個不會。
  - 你改過、清空、刪掉、新增的列和自己加的語言欄都會被取代。按一次 **復原** 可以全部還原。
  - 覆蓋的資料會成為之後「從 GitHub 更新」的比較基準。
  - 內容相同的檔案不會重寫。下載到的不是對應檔時整批不套用，原本的檔案不會被動到。

## 下載

下載 `NTE-Omikuji-v0.15.6-win-x64.exe`，放進任意資料夾直接執行，不需要安裝。`.sha256` 檔可以用來核對檔案是否完整。
